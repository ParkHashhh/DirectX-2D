# DirectX MapleStory Boss Replication

Direct3D 11(C++) 기반 미니 게임엔진을 직접 구현하고, 그 위에서 메이플스토리 감성의 2D 액션 RPG를 만든 개인 프로젝트입니다.
1인 개발, 2026.03 (4주).

## 소개

마을에서 장비와 스킬을 갖추고, 투사체 공격과 버프 스킬로 보스전에 도전하는 구조입니다.

- **자쿰전** : 팔을 하나씩 파괴할 때마다 남은 팔의 공격 패턴이 바뀝니다.
- **혼테일전** : 좌/우 손, 좌/우/중앙 머리, 다리, 꼬리, 날개까지 8개 신체 부위를 각각 파괴해야 처치할 수 있어 부위마다 다른 대응이 필요합니다.

실제 보스 패턴을 그대로 재현하기보다, 두 보스의 핵심 기믹만 뽑아 연습하는 컨셉으로 만들었습니다. 두 보스를 순서대로 격파하면 클리어됩니다.

## 실행 방법

`Binary/Client.exe`를 실행하면 빌드 없이 바로 플레이할 수 있습니다. (해상도 1280x720)

## 주요 구현

- **자쿰 (`Client/Monster/Zakum`)** : 8개 팔을 독립 오브젝트로 관리하고, 파괴된 팔 수에 따라 남은 팔의 공격 패턴(`ArmSkill`)이 바뀌는 광역 패턴 구현
- **혼테일 (`Client/Monster/HornTail`)** : 8개 신체 부위를 루트에 귀속된 독립 오브젝트로 분리해 부위별 피격/생존 판정 및 디버프(`Poison`) 처리
- **지형 이동 (`Client/Player/RayTracing`)** : Ray-Casting 기반 지형 안착 이동 컴포넌트로 캐릭터의 맵 이탈을 방지
- **커스텀 엔진 (`GameEngine/`)** : Direct3D 11 렌더러, 2D 콜라이더(Box/Line/Sphere), 2D 애니메이션, 타일맵, 포스트프로세스, 스레드 매니저 등을 엔진 코어부터 직접 설계
- **데이터 관리** : 싱글톤 기반 전역 매니저(WorldManager, ItemManager 등)와 외부 텍스트 파싱(`ItemData.txt`) 기반 아이템/드롭테이블 시스템

## 기술 스택

C++ · Direct3D 11 · HLSL · FMOD (사운드) · DirectXTex

## 유의사항

메이플스토리 원본 이미지·사운드 리소스를 학습 목적의 포트폴리오 프로젝트에 활용했습니다. 엔진 코어와 게임 로직은 모두 직접 설계·구현했습니다.
